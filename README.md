# Tic-Tac-Toe-ReactJs

Small React tic-tac-toe project with named players, turn handling, winner detection, and a lightweight browser UI.

## Why this repo exists

This repo is a compact front-end exercise for React component state, event handling, and simple game logic.

## What it does

- Collects two player names before starting
- Renders a 3x3 board
- Alternates turns between `X` and `O`
- Detects a winner through `calculateWinner()`
- Uses a simple reset flow after a win

## Run locally

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm start`
